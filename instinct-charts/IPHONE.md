أربع طرق مرتّبة من الأسهل والأرخص إلى الأكمل. اختر حسب ما تملكه الآن.

| الطريقة | تحتاج ماك؟ | تحتاج حساب مدفوع؟ | يعيش كام؟ | لمين؟ |
|---|---|---|---|---|
| ١) إضافة لشاشة الآيفون | لا | لا | للأبد | لك وللناس فورًا |
| ٢) بناء على GitHub + Sideloadly | لا | لا | ٧ أيام ويتجدّد | لك ولجهازك |

## ١) إضافة التطبيق لشاشة الآيفون — يشتغل النهاردة، ببلاش

أسرع طريقة وأرخصها، ومناسبة جدًا لتجربة التطبيق فورًا ولمشاركته مع ناس.

التطبيق مجهّز لهذا بالفعل: له أيقونة ومانيفست، ويفتح **بملء الشاشة بدون شريط سفاري**،
تمامًا كأنه تطبيق عادي.

**الخطوات:**

1. شغّل الخادم على كمبيوترك: `node server.js`
2. افتح العنوان من سفاري على الآيفون.
3. اضغط زر المشاركة (المربع والسهم لأعلى) ← **إضافة إلى الشاشة الرئيسية**.
4. هتلاقي الأيقونة على شاشتك، واضغطها تفتح بملء الشاشة.

**لكن فيه شرط:** الآيفون لازم يوصل للخادم. اختار واحدة:

- **على نفس شبكة الواي فاي:** شغّل الخادم على الكمبيوتر واعرف عنوانه المحلي
  (مثلاً `192.168.1.5`)، وافتح من الآيفون `http://192.168.1.5:8080`. يشتغل في البيت فورًا
  لكن مش هيشتغل بره الشبكة.
- **استضافة مجانية على الإنترنت:** ارفع المشروع على Render أو Railway أو Fly.io —
  كلهم عندهم باقة مجانية تكفي، والتطبيق خفيف وبلا قاعدة بيانات. ساعتها يفتح من أي مكان
  ومن أي جهاز.

**حدود هذه الطريقة:** مفيش إشعارات تنبيهات وأنت خارج التطبيق (آبل بتقيّد ده في صفحات
الويب)، ومحتاج إنترنت أول مرة. باقي كل حاجة تشتغل: الشارت، التحليل، نقاط الالتقاء،
إعادة التشغيل، والعمل بلا اتصال بعد أول فتح.

## ٢) بناء على سحابة GitHub ثم تثبيت من ويندوز — بدون ماك خالص

دي الطريقة اللي تديك **تطبيق حقيقي** على الآيفون من غير ما تشتري ماك ولا تدفع لآبل.

### أ) خلّي GitHub يبني لك الملف

جهّزت لك سير عمل جاهزًا في `.github/workflows/ios-build.yml` يشتغل على جهاز ماك تابع
لـ GitHub.

1. افتح المستودع على GitHub ← تبويب **Actions**.
2. اختر **بناء تطبيق آيفون (ipa غير موقَّع)** ← **Run workflow**.
3. استنى حوالي ١٠ دقائق، وبعدها نزّل الملف من قسم **Artifacts** أسفل صفحة التشغيل.

> ⚠️ أجهزة الماك في GitHub تُحتسب بعشرة أضعاف. لو المستودع **عام** فهي مجانية بلا حدود،
> ولو **خاص** فعندك ٢٠٠٠ دقيقة شهريًا — يعني بناء مدته ١٠ دقائق يخصم ١٠٠ دقيقة.

### ب) ثبّته على الآيفون

الملف الناتج غير موقَّع، فمحتاج برنامج يوقّعه بحساب آبل المجاني بتاعك:

- **Sideloadly** (ويندوز وماك، مجاني) — الأسهل. وصّل الآيفون بالكابل، اسحب ملف الـ ipa
  على البرنامج، اكتب حساب آبل بتاعك، واضغط Start.
- **AltStore** — بديل، وفيه ميزة إنه يجدّد التطبيق تلقائيًا كل أسبوع.

بعد التثبيت: **الإعدادات ← عام ← إدارة VPN والجهاز** ← اضغط على حسابك ← **ثق بهذا المطوّر**.
بدون الخطوة دي التطبيق مش هيفتح.

**مهم:** مع حساب آبل المجاني التطبيق **ينتهي بعد ٧ أيام** ولازم تعيد تثبيته. AltStore
بيعمل ده تلقائيًا طالما الكمبيوتر شغال على نفس الشبكة. لو دفعت ٩٩$ لآبل تبقى المدة سنة.

## ٣) ماك مع Xcode

لو عندك ماك (أو أجّرت واحدًا من MacinCloud أو MacStadium بحوالي ٢٠–٣٠ دولارًا شهريًا):

```bash
git clone <رابط المستودع>
cd instinct-charts
npm install
npx cap sync ios
npx cap open ios
```

في Xcode: اختر هدف **App** ← **Signing & Capabilities** ← فعّل *Automatically manage
signing* واختر حسابك. وصّل الآيفون بالكابل، اختاره من قائمة الأجهزة فوق، واضغط زر
التشغيل ▶.

بحساب آبل المجاني كده التطبيق يتثبّت على جهازك مباشرة — ويظل ٧ أيام قبل ما يحتاج إعادة
تثبيت. بحساب المطوّر المدفوع يظل سنة.

## ٤) TestFlight ثم App Store

لو عايز التطبيق يوصل لناس تانية بشكل رسمي:

- **TestFlight:** يحتاج حساب مدفوع (٩٩$) وماك. يسمح بحتى ١٠٬٠٠٠ مختبر، والنسخة تعيش ٩٠ يومًا.
  دي أفضل طريقة لتجربة التطبيق مع أصحابك قبل النشر العام.
- **App Store:** النشر الكامل للجمهور.

الخطوتان مشروحتان بالتفصيل في **[PUBLISHING.md](PUBLISHING.md)** — ومعهما تحذير مهم عن
ترخيص بيانات الأسعار يجب أن تقرأه قبل أي نشر عام.
